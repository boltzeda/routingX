# Contributing

Please open an issue before starting a substantial change so the scope can be
agreed on. For bug reports, include the router version, Python and KiCad
versions, the command used, and the complete error or routing-result summary.

Do not publish a PCB or project file unless you have permission to share it.
A small synthetic board that reproduces the issue is preferable. Remove
personal paths and other sensitive information from logs before posting them.

For code changes, keep the patch focused and describe how you checked it. The
supported runtime and setup instructions are in `README.md`.
